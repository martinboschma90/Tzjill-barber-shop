# Tzjill Barber Shop CMS

Kopie van het Flow Mates CMS, rebranded voor Tzjill Barber Shop. De Notype-site blijft in `notype-flow-mates`.

```bash
cd tzjill-barber-shop
npm install
cp .env.example .env.local   # eigen Supabase-keys, niet die van Notype
npm run dev
```

- Site: http://localhost:5174/
- CMS: http://localhost:5174/cms

Poort **5174** zodat Notype op 5173 tegelijk kan draaien.
